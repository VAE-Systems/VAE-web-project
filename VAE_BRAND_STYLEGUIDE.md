## 7. EFFEKTE & ANIMATIONEN

### Glow-Effekte

```css
/* Subtle Glow */
box-shadow: 0 0 20px rgba(0, 255, 165, 0.3);

/* Strong Glow */
box-shadow: 0 0 40px rgba(0, 255, 165, 0.5);

/* Ultra Glow (für Hero-Elemente) */
box-shadow: 0 0 60px rgba(0, 255, 165, 1);
```

### Gradient-Overlays

```css
/* Radial Accent */
background: radial-gradient(circle at 20% 30%, rgba(0, 255, 165, 0.1) 0%, transparent 60%);

/* Surface Gradient */
background: linear-gradient(135deg, #0a0a0a 0%, #141414 100%);
```

### Hover-Animationen

- **Lift:** `transform: translateY(-2px)` mit `transition: 0.3s ease`
- **Scale:** `transform: scale(1.02)` für CTAs
- **Glow Intensify:** Shadow-Opacity von 0.3 auf 0.5

## 10. DO'S & DON'TS

### ✅ DO

- Klare Hierarchie: Ein Headline, eine Message pro Post
- Viel Weißraum lassen (mind. 15% der Fläche)
- VAE Turquoise als Akzent, nicht als Hauptfarbe
- Konsistente Border-Radii (16px für Cards)
- Geist Font für alles außer Code
- Dark Mode als Standard, Light Mode für Abwechslung

### ❌ DON'T

- Keine Farbverläufe mit mehr als 2 Farben
- Keine anderen Grüntöne als VAE Turquoise
- Kein reines Weiß (#FFFFFF) als Fläche im Dark Mode
- Keine serifenlosen Alternativ-Fonts (bleib bei Geist)
- Keine Schatten ohne Turquoise-Tint im Dark Mode
- Keine Stockfotos – lieber abstrakte Grafiken
