# Inter local hosting

Place the following WOFF2 files in this directory to enable local Inter fonts:

- Inter-Variable.woff2 (preferred; weight range 100–900)
- Inter-Regular.woff2 (fallback 400)
- Inter-SemiBold.woff2 (fallback 600)

Optional additional weights:

- Inter-Medium.woff2 (500)
- Inter-Bold.woff2 (700)

Paths referenced by CSS:

- /fonts/inter/Inter-Variable.woff2
- /fonts/inter/Inter-Regular.woff2
- /fonts/inter/Inter-SemiBold.woff2

Notes:

- Files are not included in the repo due to environment/network constraints.
- After adding, remove any remaining external Inter <link> tags.
