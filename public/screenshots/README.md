# Screenshots für PWA Installation

Dieses Verzeichnis enthält Screenshots für die Progressive Web App (PWA) Installation.

### 1. Desktop Hero (`desktop-hero.png`)

- **Größe**: 1280x720px (16:9)
- **Inhalt**: Homepage Hero-Sektion mit VAE Branding

### 2. Mobile Services (`mobile-services.png`)

- **Größe**: 390x844px (iPhone 12-14)
- **Inhalt**: Services-Übersicht auf Mobile
- **Zweck**: Mobile-optimierte Darstellung der Services

### 3. VAE CORE Dashboard (`vae-core-dashboard.png`)

- **Größe**: 1280x720px (16:9)
- **Inhalt**: VAE CORE Plattform-Dashboard
- **Zweck**: Enterprise-Features demonstrieren

## Screenshot Guidelines:

- **High Quality**: PNG-Format für beste Qualität
- **Real Content**: Echte Inhalte statt Platzhalter
- **Responsive**: Desktop (wide) und Mobile (narrow) Varianten
- **Branding**: VAE Logo und Farben deutlich sichtbar

## PWA Vorteile:

Screenshots verbessern die App-Installation durch:

- App Store ähnliche Vorschau
- Bessere Nutzererwartungen
- Professionellere Darstellung
- Höhere Installationsraten

Um Screenshots hinzuzufügen, erstelle die entsprechenden PNG-Dateien in diesem Verzeichnis.
